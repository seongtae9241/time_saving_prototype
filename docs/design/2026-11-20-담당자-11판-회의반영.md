## 정해야 했던 것 (가정)

- **"이 분으로 확정" 대신 "이 분으로 정하기"**: 14번에서 단계 '확정'을 '최종 수락'으로 바꿔 "확정"이라는 말을 쓰지 않도록 맞춤. 정하면 '수락' 단계 → 전화 확인 뒤 '대신 최종 수락' (10판의 대신 수락 → 대신 최종 수락 흐름 그대로).
- **담당자 배분**: 박지현 = 오덕수·이순례·윤금자·정말순·서정자, 이수진 = 강만수·김영자·최복례, 최은호 = 한영자. 위임 전 시연 = 서정자 1명.
- 기관 공고 신청의 '확정' 묶음은 '수락함'으로, 공공 연계 목록 묶음 '진행 중'은 '처리 중'으로 (단계 이름과 헷갈리지 않게).
- 편성표의 이번 주 밖 날짜 일정·주별 그래프는 시연 자료(기관 전체 기준임을 표시).
- 공공 연계 서비스 찾기는 정해진 규칙으로 흉내(외부 호출 없음). 대상자 정보에 성별·장기요양 등급·기초연금 칸을 시연용으로 추가.
- 리포트 화면은 회의 (7)의 범위(데이터 필요)라 순서·범위만 바꾸고 내용은 그대로.
