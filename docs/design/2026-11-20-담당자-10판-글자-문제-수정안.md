## 1. 어떻게 점검했나 (눈이 아니라 코드로)

Playwright 브라우저 1개, 배율 1, **1440×900과 1280×800** 두 크기에서 아래 25개 상태를 차례로 열고, 매번 DOM 검사 스크립트를 돌렸다.

- 화면 16개: 홈 · 특보 알림 · 관리 대상 · 돌봄 편성표 · 요청 관리 · 공공 서비스 연계 · 기관 공고 · 기관 행사 · 권한 위임 · 리포트 · 관리 대상 상세(`care/e4`) · 요청 상세(`req/r1`) · 공공 연계 상세(`pub/pb1`) · 위임 상세(`dlg/e5`) · 대신 요청 올리기 · 도움 찾기
- 창·서랍 9개: 알림 · 공고 종류 창 · 관리 대상 수정 서랍 · 한꺼번에 공고 · 담당자 정보 · 새 위임 · 행사 올리기 · 공고 올리기 · AI 도우미(본문이 좁아지는 상태)

검사 항목(한 번 찾은 문제는 화면·선택자·글자와 함께 기록):

| 검사 | 판정 기준 |
|---|---|
| 작은 글자 | 화면에 보이는 글자 13px 미만 (그래프 글자 포함, 0px로 숨긴 화면 읽기용 글자는 제외) |
| 본문 14.5px 미만 | 24자 이상 문장인데 14.5px 미만 (보조 줄 `.muted.small`·`.sub`·`.meta`·근거 줄 제외) |
| 줄 간격 | 13~20px 글자가 여러 줄인데 줄 간격 1.45배 미만 |
| 글자 넘침 / 잘림 | 글자 실제 범위가 자기 상자 밖으로 2px 넘게 나감, `overflow:hidden`인데 말줄임 없이 잘림, 부모 상자에 가려 잘림 |
| 의도치 않은 줄바꿈 | 버튼·태그·알약·표 머리·메뉴처럼 한 줄이어야 하는 것이 두 줄 이상 |
| 짧은 칸 줄바꿈 | 16자 이하 표 칸(날짜·이름)이 두 줄 |
| 낱말 중간 줄바꿈 | 한글·영숫자 낱말 가운데서 줄이 바뀜 (`word-break:keep-all` 확인 포함) |
| 줄 높이 어긋남 | 한 줄짜리 형제들이 나란한 flex 줄에서 세로 가운데가 3.5px 넘게 다름 |
| 카드 밖으로 삐져나옴 | 카드(`.panel` `.kpi` `.dialog` `.drawer` 등) 안 요소의 아래·오른쪽 끝이 카드 밖 (떠 있는 메뉴 제외) |
| 같은 줄 카드 높이 다름 | 같은 격자 줄의 카드끼리 높이가 4px 넘게 다름 |
| 칩·탭 줄이 붙음 | 칩·탭·단계 줄과 위 제목 / 아래 표 머리 글자 사이가 14px 미만 (총괄 추가 지적) |
| 상자 안 위아래 여백 부족 | 면 색·테두리가 있는 상자 안 여러 줄 글자가 위나 아래 끝에서 10px 미만 (총괄 추가 지적) |
| 제목과 내용이 붙음 | 제목(h2·h3·접는 카드 제목) 글자와 바로 아래 내용 글자 사이 10px 미만 (총괄 추가 지적) |
| 옆 요소와 겹침 | 한 줄 안에서 한 요소의 글자가 옆 요소 상자를 3px 넘게 덮음 |
| 누를 수 없는데 색칠된 첫 카드 | 숫자 카드 줄에서 첫 칸만 색이 다른데 링크·버튼이 아님 (총괄 추가 지적) |
| 켜진 탭·칩 안 글자 대비 | 켜진(`.on`·`aria-selected`·`aria-pressed`) 탭·세그먼트·칩·줄 안 글자와 실제 바탕의 대비 3:1 미만 (총괄 추가 지적) |
| 누를 수 있어 보이는데 반응 없음 | 손가락 모양 커서인데 링크·단추·`onclick`·등록된 click/keydown 처리기가 없음 (처리기는 페이지 시작 전에 `addEventListener`를 가로채 기록) |
| 카드인데 상세 없음 | 보드 카드·행사 카드·목록 줄·표 줄인데 누를 곳이 없음 |

스크립트: 작업 폴더의 `audit.js`·`audit-in.js` (임시 폴더, 저장소에는 넣지 않음).

- 건수 = 화면 상태 × 두 크기에서 찾은 횟수, 종류 = 서로 다른 선택자 수.

## 판사 지적 반영 (10판 2차)

10판 파일에 `<style id="v10b">` · `<script id="v10b-js">` 층을 더하고, CSS로 안 되는 곳만 원본 줄을 조금 고쳤다(9판 파일은 그대로). 코랄 강조색 · 선택 상자 · navTo · 카드 끌기(`v9-drag`) · 숫자 카드 필터(`v9-kpifilter`)는 그대로 유지했고, 가중치·그림은 넣지 않았으며 가장 작은 글자는 13px이다. 1440×900과 1280×800에서 사진을 찍어 확인했다(`docs/specs/pc5/shots/proto10b-*.png`). 페이지 오류는 0건이고, 글자 점검(`audit.js`)은 고치기 전 기준과 같이 문제 0건이다. 남은 49건은 정보용 항목으로, 의도한 말줄임 31, 누를 수 없는 조치 줄 16, 원래부터 있던 대신 요청 2단계 카드 높이 2이다.
