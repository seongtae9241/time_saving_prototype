## 1. 어떻게 점검했나 (눈이 아니라 코드로)

Playwright 브라우저 1개, 배율 1, **1440×900과 1280×800** 두 크기에서 아래 25개 상태를 차례로 열고, 매번 DOM 검사 스크립트를 돌렸다.

- 화면 16개: 홈 · 특보 알림 · 관리 대상 · 돌봄 편성표 · 요청 관리 · 공공 서비스 연계 · 기관 공고 · 기관 행사 · 권한 위임 · 리포트 · 관리 대상 상세(`care/e4`) · 요청 상세(`req/r1`) · 공공 연계 상세(`pub/pb1`) · 위임 상세(`dlg/e5`) · 대신 요청 올리기 · 도움 찾기
- 창·서랍 9개: 알림 · 공고 종류 창 · 관리 대상 수정 서랍 · 한꺼번에 공고 · 담당자 정보 · 새 위임 · 행사 올리기 · 공고 올리기 · AI 도우미(본문이 좁아지는 상태)

검사 항목(한 번 찾은 문제는 화면·선택자·글자와 함께 기록):

| 검사 | 판정 기준 |
|---|---|
| 작은 글자 | 화면에 보이는 글자 13px 미만 (그래프 글자 포함, 0px로 숨긴 화면 읽기용 글자는 제외) |
| 본문 14.5px 미만 | 24자 이상 문장인데 14.5px 미만 (보조 줄 `.muted.small`·`.sub`·`.meta`·근거 줄 제외) |

| 누를 수 없는데 색칠된 첫 카드 | 숫자 카드 줄에서 첫 칸만 색이 다른데 링크·버튼이 아님 (총괄 추가 지적) |

## 2. 결과 숫자

| 검사 | 9판 (건수 / 종류) | 10판 (건수 / 종류) |
|---|---|---|
| 작은 글자 (13px 미만) | 1,585 / 128 | **0** |
| 본문 14.5px 미만 | 138 / 20 | **0** |
| 글자 넘침 | 126 / 3 | **0** |
| 제목과 내용이 붙음 | 24 / 2 | **0** |
| 칩·탭 줄이 위·아래에 붙음 | 10 / 3 | **0** |
| 카드 밖으로 삐져나옴 | 8 / 3 | **0** |
| 줄 간격 1.5 미만 | 6 / 1 | **0** |
| 줄 높이 어긋남 | 4 / 1 | **0** |
| 부모에 가려 잘림 | 2 / 1 | **0** |
| 같은 줄 카드 높이 다름 | 2 / 1 | 2 / 1 (남김, 아래 표 참고) |
| 말줄임(의도한 것, 정보용) | 30 / 2 | 31 / 2 (의도) |
| **합계(의도 말줄임 제외)** | **1,905** | **2** |

- 건수 = 화면 상태 × 두 크기에서 찾은 횟수, 종류 = 서로 다른 선택자 수.
- 9판 숫자는 지금 9판(총괄이 넣은 임시 수정 포함) 기준이다. 그래서 9판에서 이미 고쳐진 단계 칩 여백·AI 안내 상자 여백은 9판 숫자에 거의 안 잡힌다.
- 아래 3번 표의 "10판 작업 중 찾음"은 새 디자인을 얹는 동안 검사·사진으로 찾아 고친 것이다(최종 10판에서 0건).
