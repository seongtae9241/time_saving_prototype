# 기관 담당자 PC 프로토타입 11판 — UI/UX·코드 감사 2차 (2026-11-23)

## 개요

- **대상**: `docs/prototypes/proto-2026-11-20-기관담당자-PC-11.html`. 수정 1회차와 기능 추가 2회차가 들어간 판이다(6,412줄, 729KB). 파일은 고치지 않았다.
- **기준**
  - 대화 요구사항 C01~C31, M01~M17. 이를 어기는 수정안은 내지 않았다('지금' 줄 되살리기, 코랄 빼기, 그림 넣기 같은 안은 없음).
  - 1차 감사 `2026-11-23-UIUX-코드-감사-1차.md`의 U01~U26.
- **방법**: Playwright Chromium, 브라우저 1개, dsf 1. 외부 글꼴 요청은 막았다.
  - 1440×900·1280×800·390×844로 경로 27개를 열었다. 새 경로 `recur`·`classes`·`qna`, 새 상세 `care/e9`·`req/r6`·`req/r15`를 포함한다.
  - 각 화면에서 자동 감사를 돌렸다: 글자 크기, 넘침·잘림, 대비, 카드 밖 삐져나옴, 가로 스크롤.
  - 실제 클릭·입력·키보드로 1차 시나리오와 새 기능 시나리오를 다시 돌렸다. 끌기는 `page.mouse`로 단계별 이동했다.
  - CSS 덮어쓰기는 다시 분석했다: 경로 34개 × 3폭 × 밝게·어둡게, 서랍·창 27개, 대신 요청 쓰기 방법 3가지.
- **스크린샷**: `docs/qa/shots/ux2-*.png`
  - 화면 전체: `ux2-<폭>-<경로>.png`
  - 시나리오·창: `ux2-sc-*.png`
- **콘솔**: JS 오류·경고 0건, `pageerror` 0건.
- **가로 스크롤**: 3폭 모두 0.
- **자동 감사 결과**
  - 대비 미달 0건. 1차에는 `#80879A` 계열 9종이 미달이었다.
  - 13px 미만 글자 0건. 숨긴 '지금 15:50' 글자는 의도한 것이다.
  - 말줄임은 의도한 곳뿐이다. 일지 인용, 지원자 메시지, 공공 연계 서비스 이름, 옆 패널 주의사항.

## C. 바로 실행할 안전한 리팩터 계획

### C0. 화면이 같은지 확인하는 방법 (모든 단계 공통)

1. **기준 캡처를 만든다.** 지금 파일로 다음 상태를 찍는다(약 180장).
   - 경로 34개 × 1440·1280·390 × 밝게·어둡게. 배치 저장소는 비운 상태.
   - 서랍·창 27개(1440)
   - 상태 12가지: AI 도우미 열림, 1단, 오류 표시(직접 쓰기·클래스·정기 요청), 녹음 중, 통화 메모 초안, 모바일 메뉴 열림, 위험 확인 창, 토스트, `:focus-visible` 버튼, 행 마우스 올림
   - 움직임은 `prefers-reduced-motion: reduce`로 끄고, 숫자 올라가기(`countUp`)는 끝날 때까지 기다린다.
   - 시각 의존이 없도록 데모 '지금'은 고정 값(`NOW`)을 쓴다.
2. **비교한다.** 같은 스크립트로 바꾼 파일을 찍고 PIL `ImageChops.difference`로 비교한다(이 환경에 PIL 12.3 있음).
   - 통과 기준: 다른 픽셀 0. 글꼴 안티앨리어싱 때문에 다른 픽셀이 생기면 경로마다 0.01% 이하.
   - 다른 곳이 있으면 빨간 상자로 표시한 diff 이미지를 남긴다.
3. **DOM도 비교한다.** 각 상태에서 `#main`·`#layer`의 `innerText`와 보이는 요소의 `getBoundingClientRect` 목록(반올림)을 JSON으로 저장하고 비교한다. 글자·위치가 바뀐 것을 픽셀보다 빨리 잡는다.
4. **기능도 확인한다.** 1·2회차 검증 스크립트(`verify.js` 74개, `verify2.js` 92개)를 그대로 다시 돌려 PASS 166개를 유지한다.
