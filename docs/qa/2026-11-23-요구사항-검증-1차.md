# 기관 담당자 PC 11판 — 요구사항 검증 1차 (2026-11-23)

- 대상: `docs/prototypes/proto-2026-11-20-기관담당자-PC-11.html` (예시 데이터만 있음 · 서버 없음 → **API 검증 아님**, 화면 동작만 확인)
- 요구사항 출처: `docs/산출물/기능-명세서-기관담당자.md`(표 A) · `docs/qa/2026-11-23-대화-요구사항.md`(표 B)
- 방법: Playwright Chromium 헤드리스, 브라우저는 한 번에 하나만 띄움. 뷰포트 1440×900 · 1280×800 · 390×844(모바일 항목), deviceScaleFactor 1. 배치 시험 전에 localStorage를 비움. 실제로 클릭·입력하고, 마우스 down → 단계별 move → up으로 끌었음(HTML5 DnD).
- 콘솔: `pageerror` 0건. 콘솔 오류는 외부 글꼴(Google Fonts·Pretendard CDN) `ERR_FAILED`뿐이었음(오프라인으로 막아 둔 것이라 예상된 결과).
- 명세 행 ID: 원본 md 행에 ID가 없어 `시트-순번`으로 붙였음(괄호 안 Lnnn = md 줄 번호). AUTH=공통(로그인·계정), HOME=홈·특보, ELD=관리 대상, SCH=편성표·요청 관리, PUB=공공 연계·기관 공고, RPT=리포트·설정, LAY=공통 레이아웃.
- 스크린샷: `docs/qa/shots/r1-*.png`
