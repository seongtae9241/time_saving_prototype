# 담당자 프로토타입 — 대화에서 확정된 요구사항 (2026-11-16 ~ 11-20)

검증 대상: `docs/prototypes/proto-2026-11-20-기관담당자-PC-11.html` (11판)
출처: 사용자와의 작업 대화(요약 포함). 기능 명세서(`docs/산출물/기능-명세서-기관담당자.md`)·회의록(`docs/회의록/2026-11-20-기능검토-회의록.txt` 부록)과 함께 본다.

## 디자인·표현
- C01 담당자 강조색은 코랄(역할마다 다른 색). 일러스트·그림 금지(선 아이콘만).
- C02 필터는 버튼 나열보다 셀렉트 상자. 화살표는 오른쪽 끝에서 약 16px 안쪽.
- C03 가중치(난이도·배수) 없음. 1시간 = 1시간.
- C04 양옆 여백, 꽉 채우지 않기. 중요한 것이 위. 쓸데없이 큰 컴포넌트 금지. 이상한 모양 금지.
- C05 되돌봄 로고 사용. 사이드바 로고와 '기관 담당자' 배지가 한 줄.
- C06 글꼴 Pretendard(IBM Plex 쓰지 않음).
- C07 팀원 운영자 콘솔 느낌(회색 바탕·흰 카드·큰 숫자 KPI), 여유 있는 배치, 한눈에 보이게.
- C08 글자 문제 0: 넘침·잘림·어색한 위치·정렬 어긋남·13px 미만·삐져나옴·한 줄 몇 글자씩 끊김.
- C09 간격: 단계 칩 줄 위아래 여백, AI 안내 상자 위아래 여백, 접는 카드 제목↔내용 간격, 아바타↔이름 12px 이상, 제목↔부제 8px, 특보 띠 '대응 보기'·'닫기' 간격과 잘림 없음.
- C10 편성표 블록은 분류별 다른 색(같은 톤 금지). 빈칸은 빨간 점선.
- C11 '지금' 표시는 줄·글자 없이 반짝이는 동그라미만(옆 표시를 가리지 않게).
- C12 색 면 위 보조 버튼은 주 버튼과 경계가 보이게(흰 면·회색 선).
- C13 켜진 탭 안 숫자가 보이게. 탭은 흰 바탕, 켜진 탭은 연한 코랄·테두리 없음, 숫자는 동그라미 없이 글자만.
- C14 사이드바 '빈칸 N' 배지는 연한 코랄(빨간 배지는 특보만).
- C15 카드 모서리에 흰 조각·틈 없음(접는 카드·보드 포함).
- C16 지난 행사는 회색으로 구분.

## 동작
- C20 사이드바 링크가 미리보기(iframe)에서도 동작.
- C21 카드 제목을 끌어 배치 변경: 옆 가장자리 → 같은 줄 2분할, 위·아래 → 1분할(전체 폭), 2분할 카드를 위로 빼면 1분할. 담당자(회원)마다 저장되어 계속 유지. 되돌리기·기본 배치로.
- C22 좌우로 나뉜 화면(특보 등)은 끌어서 왼쪽·오른쪽 자리 바꾸기.
- C23 손잡이: 카드 맨 위 가운데, 평소 흐리고 마우스 올릴 때만 진하게, 다른 요소와 겹치지 않게(그만큼 내용 내림).
- C24 띠(특보 띠·방문 주의사항)도 옮길 수 있음.
- C25 PC에서 1단·2단 보기 선택. AI 도우미 등으로 본문이 좁아지면 자동 1단. 카드가 좁아지면 카드 안이 모바일식 배치로 바뀌어 깨지지 않음.
- C26 모바일 폭에서 사이드바가 사라지고 상단 줄·메뉴 서랍.
- C27 왼쪽 칸 따라오기(sticky) 없음(겹침 방지).
- C28 숫자 카드: 홈 카드는 화면 이동, 관리 대상·기관 공고 카드는 누르면 목록 필터(고른 카드만 색칠, 다시 누르면 전체). 누를 수 없는 카드는 누를 수 있어 보이지 않게. 기관 공고 필터가 켜지면 '전체' 탭은 테두리만.
- C29 요청 보드 빈 곳을 끌면 옆으로 스크롤.
- C30 기관 행사 카드를 누르면 상세(서랍).
- C31 요청 보드 안내 문구 색 이름이 실제 색과 일치.
