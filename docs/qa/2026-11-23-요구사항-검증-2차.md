- 사용자 결정 반영
  - 예전 앱 기능은 모두 구현함. '리포트 공유 동의'는 '보호자 공유 동의'로 이름을 바꿈. 기관 클래스는 기관 행사와 따로 있음.
  - '먼저 살펴볼 분' 줄을 누르면 관리 대상 상세로 감(HOME-03·17 충돌 해소).

  - 이관 신청과 담당 바꾸기는 '담당 넘기기'(받는 담당자가 수락) 하나로 합쳤음.
  - 글꼴은 Pretendard. LAY-22는 명세를 고칠 예정.
- 방법
  - Playwright Chromium. 브라우저는 한 번에 하나만 띄움. 1440×900·1280×800·1280×2000(끌기)·390×844, deviceScaleFactor 1. 시험마다 localStorage를 비움.
  - 실제로 클릭·입력·키보드 조작을 했음. 끌기는 page.mouse down → 단계별 move → up.
  - 1차 스크립트 33개를 그대로 다시 돌리고, 새 기능용 스크립트 19개를 더 돌렸음.
- 콘솔
  - `pageerror` 0건.
  - 콘솔 오류는 막아 둔 외부 글꼴(Google Fonts·Pretendard CDN) `ERR_FAILED`뿐.
  - 경로 29개(새 #recur·#classes·#qna 포함) × 1280·390 폭: 가로 넘침 0.
