## 단계별로 한 일

1. **죽은 JS 지우기**
   - `ART` 그림(15.7KB)과 재료 `P2`·`HOUSE`·`WIN`, `HERO_ART`를 지웠어요. `ART`는 불러온 직후 모두 `''`로 비워져 있었어요. `art()`는 `()=>''`로 바꿨고, `${ART.snow/strip/fest}` 3곳도 지웠어요(원래 빈 글자).
   - 아무도 부르지 않는 함수를 지웠어요: `oadvAsk`·`askReq`·`askMgr`·`askDecline`·`orate`.
   - 쓰지 않는 값을 지웠어요: `KTAG`·`CHK`·`bars`·`slots`·`stat`·`q3esc`·`fin`·`isP`. v10c의 `ttl`과 저장 코드(`KEY`·`load`·`save`)도 지웠어요.
   - 두 번 정의된 것을 지웠어요: 덮인 첫 `q2Switch`, v9 `mark()`. v9 `mark()`와 그 렌더 감싸기·resize·load를 지우고 qa1 `mark()` 하나만 남겼어요. 카드 제목 뽑기는 `ownT` 하나예요.
   - v10b `fc()`의 관리 대상 부분을 지웠어요. 값만 계산하고 버리던 코드예요. `CN` 표도 함께 지웠어요.
2. **훅 등록부**
   - `render()`는 이제 `beforeRender` → `renderView()` → `afterRender`를 등록 순서대로 부르는 함수 하나예요. 11개 층의 감싸기를 `onRender(...)` 등록으로 바꿨고 순서는 그대로예요. qa2 녹음 타이머 정리는 원래 맨 앞에서 돌아서 `onBeforeRender`로 옮겼어요.
   - main 스크립트 끝의 첫 `render()`를 지웠어요. 그 화면은 바로 다시 그려져 보인 적이 없어요. 이 렌더가 없어지면서 쓰이지 않게 된 원본 `vNewReq`(+`nrRun`·`postReqAI`)와 `appList`·`chatPanel`·`pickApp`도 지웠어요. 이 셋은 qa2-js가 다시 정의해요.
     - `VIEWS.newreq`는 자리만 남겼어요(`()=>''`, qa2가 `q3NewReq`로 바꿈). 처음 주소 판정(`lastView`)이 그대로이게 하려는 것이에요.
   - `q2('이름')`은 `window[이름]` 대신 이름 표 `LATE`를 봐요. qa2-js 끝에서 36개를 등록하고, 없는 이름이면 `console.error`를 찍어요. 지금 오류는 0건이에요.
   - main 스크립트 안에 있던 `openLayer`·`closeLayer`의 도장 제목 감싸기는 함수 정의에 합쳤어요(`stampTitle()`).
3. **배치 저장·현재 화면**
   - `LAYOUT_KEY='ts-layout:staff-1001'` 상수와 `layoutStore.load/save`를 하나로 만들었어요. v11 끌기와 qa1 `segFix`가 이것을 같이 써요(키를 쓰던 곳 3곳 → 1곳). 계정별 키는 사용자 결정 뒤에 켜요.
   - 현재 화면 구하기 `curView()` 하나를 kf·ev9·fc·v10c·v11·qa1이 같이 써요(6곳). 모르는 주소도 그대로 돌려줘서 예전과 같아요.
4. **CSS 죽은 규칙·덮인 선언 지우기** (판정 스크립트로 한 번에 지운 뒤 전체 비교)
   - 지운 선택자는 규칙 660개와 선택자 조각 93개예요. 조건 두 가지를 모두 맞을 때만 지웠어요.
     - 250개 상태에서 한 번도 안 맞음
     - 그 선택자에 꼭 있어야 하는 클래스·id·속성 이름이 CSS 밖(JS·마크업)에 없음. `'k-'+x`, `` `s${n}` `` 같은 조합 이름과 `dataset.x`는 있는 것으로 봤어요.
   - 덮인 선언 약 3,400개를 지웠어요. 다음 경우만 지웠어요.
     - 같은 선택자(조각까지)를 뒤에서 같은 속성(또는 그것을 덮는 짧은 속성)으로 다시 쓰고, 중요도가 같거나 높으며, 미디어 조건이 같거나 더 넓은 경우
     - 조합자 없는 덮는 선택자가 항상 같은 요소에 맞고 `!important`나 명시도로 이기는 경우
     - 대체값 모양(`dvh`·`color-mix`·접두어 등)은 건너뛰었어요.
   - 안 쓰는 `@keyframes` 5개(`inUp`·`popIn`·`pop1`·`sway`·`wxp`)를 지웠어요.
   - 상태 규칙(마우스 올림·초점·오류·끄는 중·녹음 중 등)은 캡처에 없어도 이름이 JS에 있으면 남겼어요. 그래서 비교에 안 잡히는 상태도 그대로예요.
5. **CSS 층 합치기**
   - `<style>` 23개를 `<head>`의 하나로 모았어요. 순서를 그대로 두고, 각 층은 `/* ====== 구역 N: 층 v12 … ====== */` 주석으로 나눴어요.
   - `!important`: 속성 묶음 전체가 `!important`뿐이고 인라인·애니메이션에 안 쓰이는 경우만 뺄 수 있는데, 해당은 `backdrop-filter` 1개였어요. 1,195 → 984로 줄어든 나머지는 4단계에서 덮인 선언이 지워진 결과예요.
6. **이름 바꾸기**: `mt`→`metaText`, `lim`→`limitList`. v11 안 지역 변수 `lim`은 그대로 두었어요.

## 일부러 남긴 것

- **부품별 구역 재배치(토큰 → 기본 → … → 다크)는 하지 않았어요.** 같은 명시도 규칙끼리는 순서로 이기고 지는 것이 정해져서, 순서를 옮기면 캡처에 없는 상태에서 결과가 바뀔 수 있어요. 안전한 지점(한 블록 + 층 구역 주석)에서 멈췄어요.
- `!important` 984개: 대부분 앞 층을 이기려고 붙인 것이에요. 빼면 이기는 규칙이 바뀌어서 이번에는 줄이지 않았어요. 재배치와 같이 설계해야 해요.
- 한 번도 안 맞았지만 이름이 JS에 있는 선택자 약 560개(대부분 상태 규칙)는 남겼어요. 판정만으로 지우면 캡처에 없는 화면이 깨질 수 있어서예요.
- `F`→`getFilter`, `EL`→`elderById`는 하지 않았어요. 기존 검증 스크립트(`verify.js`·`verify2.js`)가 페이지 안에서 `F()`·`EL()`을 직접 불러요. 바꾸면 스크립트 경로 말고도 고쳐야 해요.
- qa1의 `openLayer`·`closeLayer`·`confirmBox`·`drawAib` 감싸기 4개(초점 가두기·되돌리기)는 그대로 두었어요.
- 계정별 배치 키, 인라인 `onclick` 위임 전환은 범위 밖이에요.
