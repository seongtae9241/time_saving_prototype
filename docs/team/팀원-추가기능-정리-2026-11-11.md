# 팀원 자료: 시간 적금 · 추가된 기능 정리 (2026-11-11 대표 전달)

리그전·도전전에서 **"팀원 취향" 항목의 참고 자료**로 쓴다. 팀원이 프로토타입에 넣은 기능이므로, 새 아이디어가 이것을 그대로 베끼면 도전 자격이 없고, 결이 같으면 취향 점수가 오른다.

## 큰 기능 4개
### ① AI 요청 코디네이터 (도움 받기)
어디서: 홈의 "어떤 도움이 필요하세요?" 카드, 공고 탭의 "AI로 도움 요청하기"
1. 누구를 위한 요청인지 고르기: 나 / 엄마 / 아빠
2. 상황 말하기: 예시 문장을 고르거나 직접 입력
3. AI가 세 번 되물어서 요청서 완성(활동 종류마다 질문이 다름)
4. AI 요청 설계 카드: 도움 종류와 가중치, 빈도, 1회 시간, 한 달 필요 시간, 팁, JSON
5. 정기 요청 폼: 요일, 시간대, 시작일, 기간, 차감 통장(내 통장 / 가족 통장 + 몇 개월 쓸 수 있는지), 한마디
6. 등록하면 "내 정기 요청"으로 이동
- 신체 돌봄처럼 이웃이 할 수 없는 요청은 막고 공공 서비스로 안내

### ② 도움 플래너 (모으기)
어디서: 플래너 탭 → 도움 플래너 (봉사하기 모드에서 기본)
1. 3단계 인터뷰 폼: 생활 패턴(일하는 요일, 퇴근 시간, 빈 시간대) / 몸과 이동(체력, 이동 수단, 운전, 거리) / 하고 싶은 도움·꺼려지는 도움
2. AI 추천 루틴: 한 달 봉사 시간과 적립 시간, 루틴 3개(요일·시간·이유)
3. 약정형 봉사 적금: 약정 폼 또는 이번 달 진행 상황
4. 이번 주 실행: 루틴에 맞는 실제 요청을 [제안] / [건너뛰기]
5. AI 재조정 제안: "수요일 안부를 2번 건너뛰셨어요 → 일요일로 바꿀까요?"
6. 분기 리뷰: 계획 대비 실제 그래프, 3개월 요약

### ③ 시간 플래너 (쓰기)
어디서: 플래너 탭 → 시간 플래너 (도움 받기 모드에서 기본)
1. 조건 입력: 지금 나이, 받기 시작할 나이, 한 달 모을 시간, 받고 싶은 도움, 가족 선물 시간
2. 결과: 몇 살까지 받을 수 있는지, 나이별 통장 그래프, AI 조언
3. "모으는 방법 짜기 ›"로 도움 플래너와 연결
4. 생애 시간 계획 타임라인의 마지막 단계에 시간 상속
5. 시간 상속 설계와 가족 시간 통장으로 바로 이동

### ④ 내 통장에 물어보기 (통장 비서)
어디서: 통장 탭 상단, 리포트 하단
- 질문 6가지: 잔액 / 올해 동행 적립 / 작년 대비 / 목표 진행 / 100시간 예측 / 엄마에게 선물
- AI가 호출한 함수가 순서대로 보이고 → 한 줄 답 → 근거(표, 그래프) → 다음 행동 버튼
- 선물은 확인 카드를 거쳐야 실행

## 플래너 탭 (3칸)
일정(달력·요약) / 도움 플래너(어떻게 모을까) / 시간 플래너(언제 쓸까)

## 부가 기능
### 도움 받기 쪽
- 효도 요청: 코디네이터에서 받는 사람을 엄마·아빠로. 요청은 부모님 동네로 올라가고 최종 수락은 부모님이.
- 내 정기 요청: 회차 진행 막대, 다음 일정, 단골 시간메이트, AI 조정 제안("장보기 후 말동무 30분 추가할까요?"), 수정 / 일시정지 / 해지
- 서류 도우미: 기초 연금 신청서, 에너지 바우처 신청서, 고지서를 찍으면 칸마다 쓰는 법을 알려 주고 어려운 칸은 "신청 동행 요청"으로 연결
- 혜택 찾기: 나이, 사는 곳, 함께 사는 사람, 소득, 거동을 넣으면 받을 수 있는 혜택 5개를 가능성·이유와 함께. 서류 도우미나 신청 동행으로 이어짐.

### 봉사하기 쪽
- 약정형 봉사 적금: 월 약정 시간, 회차, 이번 달 진행, 이번 주 AI가 고른 봉사 → [수락]
- 묶음 추천: 같은 날 같은 동네 요청 2건을 묶어 한 번에 제안(홈, 공고, 도움 플래너)
- 사진 인증: 활동 일지에서 활동별 분석 — 장보기 → 영수증 정리(가족 공유) / 생활 정리 → 고지서 쉬운 말 요약 / 동행 → 약 봉투로 복용 시간표 / 디지털 → 따라 하기 카드 / 집안일 → 전후 사진 / 말동무 → 얼굴 가린 활동 인증
- 사진 인증 내역: 올해 인증 목록(적립 근거)

### 통장 쪽
- 월간 리포트: 월 이동, AI 해설, 적립·사용·순증, 목표 대비, 활동별 도넛, 가중치 보너스, 다음 달 제안
- 가족 시간 통장: 가족 4명 잔액, AI의 "어떤 시간부터 쓸까" 추천, 함께 쓰는 규칙, 가족 내역, 가족 통장에 넣기
- 시간 상속 설계: 기준(지금 잔액 / 플래너 예상) → 받는 사람별 비율 → 넘기는 방식과 조건 → AI 설계 결과(넘기는 순서 타임라인)
- 모드별 메뉴: 도움 받기는 "시간 쓰기"(효도 요청, 선물, 가족 통장, 상속), 봉사하기는 "시간 모으기"(약정, 도움 플래너, 사진 인증, 묶음, 확인서)

## 모드별로 바뀌는 화면
| 화면 | 도움 받기(파랑) | 봉사하기(초록) |
|---|---|---|
| 홈 | AI 요청 도우미, 정기 요청, 내 요청함, 도와줄 수 있는 이웃 | 약정 적금, 사진 인증할 활동, 봉사 요청함, 묶음 추천, 도움이 필요한 이웃 |
| 공고 | 도움 가능 공고 | 봉사 요청 공고 + 묶음 추천 |
| 플래너 | 시간 플래너 먼저 | 도움 플래너 먼저 |
| 통장 | 시간 쓰기 메뉴 | 시간 모으기 메뉴 |
| 내 활동 | 받은 요청 + 정기 요청 | 내 봉사 |

## 총괄 메모 — 우리 서비스의 지금 결정과 부딪히는 부분(팀 논의 필요)
- **시간 상속**: 요구사항 B-34는 "선물 외 양도·매매·상속 불가". 팀원 안은 상속을 넣음.
- **가족 시간 통장(함께 쓰는 통장)**: 지금은 가족에게 "선물"만 가능(B-32).
- **사진 인증의 "약 봉투로 복용 시간표"**: 의료·건강 정보에 닿음(진단·건강 판단 금지, 의료 행위 금지와의 경계 확인 필요).
- **혜택 찾기의 "받을 가능성"**: 요구사항 P-01은 "자격 판정은 하지 않고 기관 확인 안내".
- **서류 도우미·사진 인증**: 사진에 주민번호·금융 정보가 찍힘(무료 AI 등급으로는 실사용 불가).
