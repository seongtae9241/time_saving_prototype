## 쪽 구성

Starter 요금제는 한 파일에 쪽이 3개까지라, 요청한 5쪽을 3쪽으로 묶었습니다.

| 쪽 | 내용 | 프레임 수 |
| --- | --- | --- |
| 0. 표지·안내 + 4. 화면 흐름 | 공용 컴포넌트 한 묶음만 있음(왼쪽 메뉴 2종, 상단 바 2종, KPI 카드, AI 카드, 버튼 7종, 상태 배지 6종). 표지·화면 목록·흐름은 없음 | 1 |
| 1. 기관 담당자 (PC) | 담당자 화면 25개 전부 + 탭 변형 3개 + 실제 앱(5판) 기준 3개. 1440 폭, 프레임마다 오른쪽에 노란 주석 메모 | 31 |
| 2. 운영자 (PC) + 3. 사용자 (모바일) | 운영자 화면 10개 전부 + 패널 변형 1개. 사용자 화면은 없음 | 11 |

- 주석 메모 내용: 목적, 주요 동작(버튼 → 이동 화면 ID), 상태, 이미 있는 API, 새로 필요한 서버 기능.
- 초록 테두리 = 그 화면 ID가 가리키는 영역(목록 옆 상세). 점선 회색 카드 = 다른 상태 참고. 보라 카드 = ✨ AI 결과.

## 확인한 것

스크린샷으로 본 프레임: O-HOME-01 홈, O-SCHED-01 돌봄 편성표, O-CARE-03 등록 패널, O-RPT-01 리포트, O-POST-03 요청 상세, O-HOME-01 홈 / 5판. 글자 겹침·넘침 없음.

## 못 만든 것 (2026-11-16 기준)

원인: Figma가 "Starter 요금제의 MCP 도구 호출 한도에 도달했다"며 그리기·스크린샷 호출을 모두 거절합니다. 한도가 풀리거나(기간은 Figma 안내 확인 필요) 요금제를 올려야 이어서 할 수 있습니다. 요금제 변경은 돈이 드는 결정이라 하지 않았습니다.

- 사용자 (모바일) 화면 전부 (390×844, 기획서 6절·8절)
- 표지·안내(색, 반응형 원칙, 표기 규칙, 화면 목록 표)
- 화면 흐름(기획서 3절)
- 운영자 프레임 줄 맞춤과 쪽 제목, 운영자 5판 모양 프레임
- 담당자 나머지 화면의 5판 모양 변환(관리 대상·요청 상세·특보 등 2차 사진 기준)
- 0쪽에 숨겨 둔 작업용 프레임 `_도우미 (작업용 · 끝나면 지움)` 삭제 — 숨김 상태라 보이지 않지만 남아 있습니다. 이어서 작업할 때 필요하므로 작업이 다 끝난 뒤 지우면 됩니다.
