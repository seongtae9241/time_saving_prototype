## 알아 둘 것

- 지금 프레임은 **PC 프로토타입 4판 모양**(어두운 왼쪽 메뉴 220px, 담당자 초록 `#4FAE96`, 운영자 주황 `#E0A23E`)입니다. 실제 앱에 들어간 **5판 모양**(흰 왼쪽 메뉴 236px, 위 막대 `#3E9E85`·`#DD9424`, 카드 반지름 22)과 다릅니다.
- 글꼴은 Pretendard가 Figma에 없어 Noto Sans KR을 썼습니다.
