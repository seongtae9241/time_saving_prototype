# 프로토타입 대조표 (2026-11-11 역할별 정리판)

기준: `docs/prototypes/proto-2026-11-11-역할별정리판.html`(끝에 덧붙은 패치까지 적용된 **최종 동작**), `docs/specs/2026-11-11-역할별-기능목록.md`.
방법: 프로토타입과 앱을 400×860 화면으로 나란히 열어 비교했다. "나란히 봄"은 스크린샷으로 맞춘 화면, "열어 봄"은 새 CSS를 입힌 뒤 오류 없이 열리는 것만 확인한 화면이다(세부 모양은 하나하나 대조하지 않았다).

## 공통

| 항목 | 프로토타입 | 예전 앱 | 조치 |
|---|---|---|---|
| CSS | `<style>` 1,347줄(v4~v11 + 11/10 파스텔) | 이전 프로토타입 CSS | `frontend/src/styles/proto.css`를 새 프로토타입 `<style>`로 **통째로 교체**. 프로토타입에 없는 화면용 규칙(첫 활동 교육·QR·지각 안내)과 접근성 보정은 `kept.css`로 분리 |
| 아이콘 | 듀오톤 `dIc`/`DI`/`DC` | 선 아이콘 | `ui/duoIcons.js`(그대로 옮김) + `DIc`. 카테고리 아이콘·칩도 듀오톤으로 |
| 헤더 칩 | 사용자는 "도움 받기 / 봉사하기"(주황/초록 점), 누르면 "지금 할 일" 시트 | "사용자" 고정, 홈 안 세그먼트 | 전역 모드(`ModeProvider`, localStorage `ts-mode`)로 올림. 시트 위쪽에 모드 고르기, 아래에 데모 계정 |
| 아래 탭(사용자) | 홈 / 공고 / 내 활동 / 시간 통장 / 마이 | + 동네 소식(6칸) | 5칸으로. 동네 소식은 홈 섹션·마이 메뉴에서 들어감 |
| 아래 탭(담당자) | 4번째 "최근 기록" | "리포트" | 이름 바꿈 |
| 공고 종류 이름 | 도움 가능 / 봉사 요청 | 봉사 가능 / 도움 요청 | 화면 문구 전부 바꿈(API 값은 그대로) |
| 시간 표기 | "23시간 30분" | "23.5시간" | 통장·홈·플래너·요청 배너는 프로토타입 표기, 나머지 화면은 기존 0.5 단위 표기 |

## 프로토타입과 다르게 둔 것

| 무엇 | 프로토타입 | 앱 | 이유 |
|---|---|---|---|
| 플래너 | 한 화면에 이어짐 | 위에 3칸 칩(캘린더/추천 봉사/생애 플랜) | 기능 목록이 3칸을 요구 |
| 플래너 "계획 세우기" | "요청도 함께 보냈어요" | 달력에만 넣고, 제안은 공고에서 직접 | 결정은 사람이 버튼으로 |
| 플래너 달력의 기관 소식 | 모든 소식 | 내가 신청한 소식만 | 내 확정 일정을 보는 달력 |
| 생애 플랜 "가족에게 선물할 시간" 슬라이더 | 초기 버전에만 있음(최종 화면엔 없음) | 없음 | 최종 화면 기준. 상속은 넣지 않음 |
| 내 활동 | 나눔 없음 | 도움받기/봉사하기 버튼 | 기능 목록 요구 |
| 통장 번호 | 1004-26-118422 | TS-000001(회원 번호) | 실제 값 |
| 요청 진행 단계 | 5단계 | 6단계("활동 중" 포함) | QR 시작·종료(유지 기능) |
| a_dash 공공 DB 메뉴 | 뺌 | 남김 | 유지 기능(공공 서비스 DB 관리) |
| a_verify 설정의 효력 | "새로 가입한 사람부터 적용" | 저장·표시만 | 실제 봉사 조건 변경은 규칙 결정이 필요(화면에 안내문) |
| 보조 글씨 색 | #A3ACBA 등 | #687080 등 | 대비 4.5:1 유지(회색 글씨만) |

## 프로토타입에 자리가 없어 옮겨 둔 기존 기능

| 기능 | 지금 자리 |
|---|---|
| 물어보기(`/ask`), 말로 요청하기(`/voice`), 이번 주 기관 클래스 | 홈 맨 아래 "말로 편하게" |
| 말로 요청하기, 봉사 요청 직접 적기 | 공고 올리기(`/write`) 큰 버튼 아래 줄 |
| 첫 활동 교육(`/edu`) | 홈(봉사하기) 아이콘 "활동 교육"(미수료면 진행 단계 표시), 마이 메뉴 |
| 방문 전 브리핑 버튼 | 홈(봉사하기) "내 일정" 아래(가장 가까운 일정), 요청 상세 |
| 동네 소식 전체 목록(`/news`), 기관 클래스 추천 | 홈 "동네 기관 소식 › 전체", 마이 메뉴 |
| 내 봉사 플랜(남은 시간 계산·거꾸로 플랜, `/bank/plan`) | 플래너 → 생애 플랜 맨 아래 버튼 |
| 관심 공고 알림(`/my/alerts`) | 공고 탭 "관심 조건", 마이 메뉴 |
| 담당자: 단골에게 요청, 말로 공고 만들기, 통화 메모로 여러 건 | 담당자 홈 아이콘 아래 버튼 |
| 담당자 주간 브리핑 | 담당자 홈 아이콘 메뉴 아래 |
| 운영자: 공공 서비스 정보, 기관 클래스, 가상 상대 관리 | 관리 메뉴(그대로) |
