# 역할별 기능 목록 (2026-11-11 대표 전달) — 구현 기준

기준 프로토타입: `docs/prototypes/proto-2026-11-11-역할별정리판.html`

## 사용자
- 공고 올리기: 수동 / 자동(AI). 지난 공고 다시 올리기는 가져간다.
- 헤더에서 봉사받기 / 봉사하기를 바꾸면 화면 세팅이 알아서 바뀐다.
- 통장: 통장 내역, 사용 내역 — 상단에는 총 합산(앱을 쓰면서 총 몇 시간 벌었는지, 총 몇 시간 썼는지), 하단에는 월 내역. 시간 선물하기 → 가족 연결.
- 봉사 일지 → 담당자에게 전달되는 것. 시작·종료 QR.
- 마이페이지에 가족 연결.
- 플래너 탭: 1. 캘린더 2. 추천 봉사 3. 생애 플랜
- 내 활동 → 도움받기 / 봉사하기로 나눈다.
- 단골 등록: 수동, 세 번 이상 만나면 자동 등록.
- AI 추천: 내가 필요한 도움을 넣으면 근처 사람 추천(공고 기준으로 시간·지역이 잘 맞는 사람. 공고 중 단골이 있으면 좋고 아니어도 시간·지역이 맞아야 함). 받을 수 있는 도움도 얘기해 준다. **단골 추천 섹션과 가까운 사람 추천 섹션이 나뉘어 있어야 한다.**
- 공공 서비스는 AI가 말해 준다 → 근처 공공기관을 말해 준다. 봉사에 대한 정보.
- 동네 기관 행사 홍보 정리 페이지(근처 지역으로 찾아야 함).
- 봉사 카테고리에 없는 카테고리를 추가하고 싶으면 운영자에게 건의하는 기능.

## 담당자
- 대리 봉사 요청 공고 업로드: 수동 / AI. 공고를 올릴 때 관리 대상의 이슈를 적는다.
- 관리 대상 정보 등록: 관리하는 사람들 정보를 등록해야 그 사람들 대신 공고를 올릴 수 있다.
- 도움 찾기
- 기관 행사 올리기
- 관리 대상 대신 제안 수락 / 거절
- 프로필 메모 → 관리 대상의 이슈를 메모
- 리포트 → 관리 대상 동향 파악, 관리 우선순위 체크

## 운영자
- 봉사 유형 리포트, 나이별 인기 봉사, 수요·공급 비교, 계절별 봉사 리포트
- 기관 승인, 신고 관리, 문의하기
- (추가) 카테고리 건의 처리
