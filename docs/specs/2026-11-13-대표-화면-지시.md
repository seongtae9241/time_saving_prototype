# 2026-11-13 대표 화면 지시 (원문 정리)

반응형 — 사용자: 모바일(PC에서도 모바일 모양) / 담당자·운영자: PC

## 사용자 · 도움 받기
### 홈
- 하단바: 홈, 공고, 시간통장, 플래너, 마이페이지
- 시간 통장 요약: 통장 번호, 이름, 쓸 수 있는 시간, [내역 보기], [선물하기]
- 내 다음 일정: 도움 받기가 확정된 것
- (도움 요청, 단골 요청, 공공 서비스, AI 추천 — 작은 사각형 메뉴는 봉사하기·봉사받기 홈에서 없앰)
- 도와줄 수 있는 이웃
### 공고
- 탭: 1:1 공고 / 단체 봉사 / 동네 기관 소식
- 각종 공고 필터링 버튼
- 관심 공고(없으면 공고 카드 최신순) → 그 아래 공고 카드 최신순
- 단체 봉사도 공고 카드처럼
- 동네 기관 소식: 최신순으로 공고 카드처럼, 누르면 기관 페이지 링크
- 공고에 "내가 도와줄 수 있는 이웃" → 공통
### 시간 통장
- 통장 번호, 예금주, 쓸 수 있는 시간, 총 모은 시간, 총 사용 시간, [가족에게 선물하기], 플래너
- 거래 내역: 월별 필터링, 최신순, 몇 시간 벌었고 사용했는지, 잔액, 도움 준 사람
### 시간 플래너
- 생애 플랜 꺾은선 그래프
- 순서: 생애 플랜 → 캘린더 → AI 도움 추천
- 북마크는 캘린더에 관심 공고 느낌으로(달력에는 안 뜸)

## 사용자 · 봉사하기
- 홈: 도움 가능은 하나의 메뉴로(내 일정, 받은 요청, 기관 요청과 같이). 봉사 확인서는 아래쪽에 하나의 메뉴로
- 작은 사각형 메뉴는 봉사하기·봉사받기에서 없음
- 봉사 요청 공고 상세: 시간 → 필요한 도움 → 내용 → 특이사항(요청자, 담당자)
- 봉사 상세 내역: 봉사 일지

## 마이페이지
- 가족 대신 올리기 → 공고로 옮김
- 가족 최근 기록은 뺌
- 내 리포트 공유는 뺌

## 확인할 것
- 상단에 알림 느낌으로 공지가 나오는지(대표: 기억이 안 난다)
