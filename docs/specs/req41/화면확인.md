1. **동네 기관 소식의 표시가 세 가지다.** 프로토타입은 "담당자가 올림" / "AI가 찾음 · 출처 확인" 두 가지인데, 지금은 공공데이터 강좌에 "공공데이터 · 출처 확인"이 따로 붙는다(`screens/news.jsx:15`). AI 키가 없는 지금은 "AI가 찾음" 카드가 하나도 안 보인다.
2. **소식 화면 위 문구**: 프로토타입 "접속 위치 기준" ↔ 지금 "내 동네 기준"(적용-org.md에 이유가 적혀 있음). 담당자 계정은 동네가 없어 "📍 동네 미설정 근처"로 나온다 — 담당자에게 기관 동네를 보여 줄지 정해야 한다.
3. **첫 활동 연습 수료 배지**: 프로토타입에는 있고 명세 B-54는 없음. 지금은 명세대로 없다(이미 대표 확인 요청 중).
4. **가족 대신 올린 공고**를 올린 사람이 열면 "여기서는 진행 상황만 볼 수 있어요"라고 하면서 [수정] [삭제] [다시 올리기] 버튼이 함께 보인다. 올린 사람이 고치고 지울 수 있게 둘지, 가족 본인만 하게 할지.
5. **관심 조건 [+ 조건 추가]**의 처음 값이 "행복동 · 주말 · 디지털 도움"으로 미리 골라져 있다. 다른 것만 고르고 저장하면 뜻하지 않게 주말·디지털 도움이 같이 들어간다(확인 때 실제로 그렇게 저장됨). 비워 둘지.
6. **지난 공고 불러오기** 뒤 날짜가 내일로 미리 골라져 있어 "날짜를 골라 주세요" 안내와 달리 날짜를 안 골라도 바로 등록된다. 날짜를 비워 두고 고르게 할지.
7. **대화형 작성**에서 "몇 시간 정도 걸릴까요?" 질문 아래 빠른 답 칩이 "오후 2시~5시 / 오전 10시~12시 / 저녁 6시~8시"(시간대)로 나온다. 질문에 맞게 "1시간 / 2시간…"으로 바꿀지.
8. **올린 파일(재직 증빙·신분증 등)은 로그인 없이 주소만 알면 열린다**(`GET /api/files/**` 공개, 파일 이름은 무작위). 운영자가 새 창으로 열기 위한 구조인데, 민감한 서류라 로그인·역할 확인을 넣을지.
9. **관심 공고 알림**(시연 자료)을 누르면 해당 공고가 아니라 홈으로 간다. 실제로 만들어지는 알림도 그런지는 새 공고로 알림을 일으켜 보지 못했다.

## 4. 작은 문구·시연 자료 문제 (고치지 않음)

- 기관 신청 시연 자료 2건: "재직증명서 첨부"와 "제출된 파일이 없어요 (41판 이전 신청)"가 같이 보인다.

- 가족 대신 공고 알림의 날짜만 `2026-11-20` 형식이다(다른 알림은 `11/20`).

## 5. 못 본 화면과 이유

- **시간이 지나야 생기는 것**: 24시간 자동 만료·자동 확정, 리마인드, 지각·노쇼 알림, 시간 조정 요청, 스케줄러.
