## 1. 공통 규칙

### 1-1. PC 화면 원칙
| 원칙 | 설명 | 쓰는 화면 |
| --- | --- | --- |
| 목록 + 상세 한 화면 | 왼쪽 목록에서 고르면 오른쪽에 상세가 바로 떠요. 화면을 넘기지 않아요 | 관리 대상, 요청 관리, 공공 서비스 연계, 권한 위임, 리포트, 승인, 신고, 문의 |
| 작은 일은 그 자리에서 | 수락·거절·상태 변경은 표 안이나 상세 패널 버튼으로 끝내요 | 홈, 요청 관리, 공공 서비스 연계 |
| 입력은 오른쪽 패널 | 등록·수정은 오른쪽에서 밀려 나오는 패널. 뒤 화면이 그대로 보여요 | 관리 대상 등록, 기관 공고 쓰기, 새 위임, 공공 서비스 정보 |
| 고르기는 가운데 창 | 여러 개 중 하나를 고르거나 한꺼번에 처리할 때 | 공고 유형 고르기, 빈칸 한꺼번에 올리기 |
| AI 결과 카드 | AI 결과는 보라색 카드(✨ 제목 + 내용 + "근거 · …" 한 줄)로 통일 | 모든 ✨ 화면 |

| 항목 | 내용 |
| --- | --- |
| 목적 | 오늘 처리할 일과 챙길 분을 한눈에 보고 바로 처리 |
| 진입 | 로그인, 왼쪽 메뉴 홈 |

| 영역 | 구성 요소 | 표시 내용 · 규칙 | 동작 |
| --- | --- | --- | --- |
| 맨 위 | 특보 배너 | 운영자가 보낸 특보만. 내용, 권장 조치 한 줄 | `[혼자 사는 분 보기]` → O-CARE-01(필터) · `[닫기]` |
| KPI 4칸 | 관리 대상 / 이번 주 돌봄 / 처리할 일 / 편성 빈칸 | 숫자 + 보조 설명 (우선순위 높음 n명, 완료·예정, 대신 수락·일지, ✨ 대안 있음 n개) | 카드 클릭 → 해당 메뉴 |
| 왼쪽 | 오늘 처리할 일 표 | 관리 대상, 내용(카테고리·할 일), 봉사자, 일시 | 제안 도착: `[대신 거절]` `[대신 수락]` · 봉사자 수락: `[전화 확인 후 수락]` → O-POST-03 · 일지: `[일지 확인]` → O-POST-03 |
| 왼쪽 | 이번 주 편성 미리보기 | 작은 편성표, 빈칸 빨간 점 | 칸 클릭 → O-SCHED-01 |
| 오른쪽 | ✨ 먼저 안부를 물어볼 분 Top 3 | 순위, 이름·나이, 이유 한 줄 · 근거: 최근 4주 일지·요청·취소 | 클릭 → O-RPT-02 |
