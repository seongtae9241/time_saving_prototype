# 기관 클래스 데이터 넣기 (기관 클래스 추천)

"동네 소식" 맨 위 **가까운 기관 클래스**는 세 곳에서 모은 강좌를 보여 줍니다. 신청은 기관 사이트에서 하고, 강좌는 시간 통장 시간을 쓰지 않습니다.

| 경로 | 넣는 사람 | 필요한 것 | 확인 |
|---|---|---|---|
| ① 공공데이터 파일(CSV) | 운영자 | 없음(키 없이 됨) | 공공 데이터라 바로 보임 |
| ② AI 웹 검색 | 운영자(지역 다시 찾기) · 사용자("내 위치로 다시 찾기") | **Gemini 키** | 서버가 안내 페이지를 직접 열어 제목을 얻은 것만 보임 |
| ③ 기관 소식 | 기관 담당자(동네 소식 올리기) | 없음 | 담당자가 올린 그대로 |

처음 실행하면 "(예시)"가 붙은 샘플 강좌 7개가 들어 있습니다. 실제 강좌가 아니니 실제 데이터를 넣은 뒤 운영자 화면에서 숨기거나 지우세요.

## 1. 공공데이터포털에서 평생학습강좌 파일 받기

1. **공공데이터포털**(https://www.data.go.kr)에 들어갑니다. 파일을 받는 것만은 로그인 없이 되는 경우가 많습니다(안 되면 회원가입·로그인).
2. 검색창에 **"평생학습강좌 표준데이터"** 또는 **"전국평생학습강좌표준데이터"**를 넣고 찾습니다.
3. **파일데이터** 탭에서 그 항목을 열고 **CSV 다운로드**를 누릅니다.
   - 우리 동네 것만 필요하면 시·군·구청이나 평생학습관이 따로 올린 "평생학습 강좌 현황" 파일을 받아도 됩니다(열 이름이 조금 달라도 비슷하면 맞춰 읽습니다).
4. 파일을 열어 볼 필요는 없습니다. 엑셀에서 열고 저장했다면 **CSV(쉼표로 분리)**로 저장하세요.

> 표준데이터는 전국 강좌가 많아 파일이 클 수 있습니다. 한 번에 5,000줄까지 읽습니다. 크면 엑셀에서 우리 시·군·구 줄만 남겨 저장해 올리세요(최대 10MB).

## 2. 운영자 화면에서 올리기

1. 운영자 계정(데모: `admin` / `1234`)으로 로그인 → 아래 탭 **관리** → **기관 클래스**.
2. **공공데이터 CSV 가져오기**에서 파일을 고르고 **가져오기**를 누릅니다.
3. 결과에 글자 코드(UTF-8·CP949 모두 자동), 새로 넣은 수, 끝나서 뺀 수, **맞춘 열**과 원본으로만 보관한 열이 나옵니다.
   - 읽는 열: 강좌명, 강사명, 교육시작일자, 교육종료일자, 교육시작시각, 교육종료시각, 교육요일, 교육대상, 교육방법, 수강정원, 교육비(수강료), 교육장소, 교육장도로명주소, 운영기관명, 운영기관전화번호, 접수방법, 홈페이지주소, 위도, 경도.
   - **이미 끝난 강좌는 넣지 않습니다.** 같은 파일을 다시 올리면 새로 넣지 않고 고칩니다.
   - "강좌명 열을 찾지 못했어요"가 나오면 평생학습강좌 파일이 맞는지 확인하세요.
4. 사용자 화면(동네 소식)에서 사용자의 동네·나이대·관심 분야에 맞춰 순서가 정해집니다(같은 동네, 휴대폰·디지털과 정서·건강 강좌, 날짜가 가까운 강좌가 먼저).

## 3. AI 웹 검색 켜기 (선택)

- **Gemini 키가 있어야** 켜집니다. 키 받는 법·넣는 법: `docs/guides/gemini-무료키-발급.md` (새 환경변수는 없습니다. `GEMINI_API_KEY` 하나만).
- `AI_PROVIDER=anthropic`이거나 규칙 모드이면 꺼집니다(Claude에는 이 검색 기능을 쓰지 않습니다).
- 운영자 화면 **지역 다시 찾기**에 "금천구 독산동"처럼 시군구·동을 넣고 누릅니다. 사용자는 동네 소식의 **내 위치로 다시 찾기**를 누릅니다(위치는 그때 한 번만, 약 1km 단위로 줄여 씁니다).
- AI가 준 강좌 중 **안내 페이지 주소가 없는 것은 버리고**, 서버가 주소를 직접 열어 **제목을 얻은 것만** 보여 줍니다. 못 연 것은 숨김으로 남습니다(운영자 목록에서 "확인 못 함").
- 같은 지역은 **하루에 한 번**만 찾습니다(운영자 "다시 찾기"는 언제든).
- 화면에는 "AI가 찾은 정보 · 신청 전 기관에 확인"이 붙습니다. AI가 날짜·장소를 틀릴 수 있습니다.
- **무료 한도**: Gemini 무료 등급은 구글 검색 그라운딩 요청 수에 하루 한도가 있고, 한도가 바뀌거나 모델에 따라 쓸 수 없을 수 있습니다. 한도를 넘으면 "지금은 AI 검색을 할 수 없어요"가 나오고, 이미 모은 강좌는 그대로 보입니다.

## 4. 관리

- 운영자 **기관 클래스** 목록에서 출처(공공데이터·AI 검색·기관 소식)와 확인 여부를 보고 **숨기기/삭제**할 수 있습니다. 기관 소식은 숨기기만 됩니다(지우기는 담당자가 마감).
- 담당자는 도움 대상 상세의 **이 어르신께 맞는 기관 클래스**에서 강좌를 보고 **동행 요청 대신 만들기**로 이어 갈 수 있습니다.
