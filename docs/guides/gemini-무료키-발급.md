# Gemini 무료 API 키 받는 법 (시간 적금 AI 켜기)

시간 적금은 AI 키가 없으면 "규칙 모드"로 돌아갑니다. Gemini 무료 키를 넣으면 다음 기능이 실제 AI로 바뀝니다.
- 대화형 공고 작성
- 금지 요청 판정
- 난이도 제안
- 일지 정리
- 공공 서비스 안내
- 역할극
- 리포트
- **서버 음성 인식**

## 1. 키 발급 (5분, 카드 등록 없음)

1. 구글 계정으로 **Google AI Studio**에 들어갑니다: https://aistudio.google.com
2. 왼쪽 아래 또는 오른쪽 위의 **"Get API key"**(API 키 가져오기)를 누릅니다.
3. **"Create API key"**(API 키 만들기)를 누르고, 프로젝트를 고르라고 하면 새 프로젝트를 만듭니다.
4. 만들어진 키(`AIza...`로 시작)를 복사합니다.
   - 키는 비밀번호와 같습니다. 카톡·메일·깃허브에 올리지 마세요.
   - 실수로 올렸다면 AI Studio에서 그 키를 지우고 새로 만드세요.

## 2. 서버에 키 넣기

키는 **파일에 적지 말고 환경변수로만** 넣습니다.

**Windows (PowerShell)**: 그 창에서만 유효합니다.
```bash
$env:GEMINI_API_KEY="여기에_복사한_키"
```
```bash
java -jar backend/target/time-savings-0.1.0.jar
```

**Mac / Linux**
```bash
GEMINI_API_KEY="여기에_복사한_키" java -jar backend/target/time-savings-0.1.0.jar
```

**개발 모드(`./mvnw spring-boot:run`)도 같은 방법으로 환경변수를 먼저 넣고 실행합니다.**

선택 설정:
- 모델 바꾸기: `GEMINI_MODEL` (기본 `gemini-flash-latest`). 무료 한도가 부족하면 `gemini-flash-lite-latest`처럼 Flash-Lite 계열로 바꾸면 하루 호출 수가 더 넉넉한 편입니다.
- AI 공급자 고르기: `AI_PROVIDER=gemini|anthropic|rule`. 비워 두면 키가 있는 쪽을 자동으로 고릅니다(Gemini 우선).

## 3. 잘 켜졌는지 확인

- 운영자(`admin`)로 로그인하거나, 브라우저에서 `/api/ai/status`를 엽니다. `provider: "gemini"`가 나오면 성공입니다.
- 화면의 AI 결과 아래 작은 글씨 "AI 키 없음 · 규칙 모드"가 사라집니다.

## 4. 알아 둘 것

- **무료 한도는 Google이 자주 바꿉니다.** 분당 몇 번, 하루 몇십~몇백 번 수준입니다. 지금 내 한도는 AI Studio의 사용량(Usage)·한도(Rate limit) 화면에서 확인하세요.
- 한도를 넘으면 그 순간만 규칙 모드로 자동 전환되고, 서비스는 멈추지 않습니다.
- **무료 등급에서 보낸 내용은 Google이 서비스 개선에 쓸 수 있습니다.** 프로토타입 시험에서는 실제 이름·전화번호·주소 같은 개인정보를 넣지 마세요. 실제 서비스로 갈 때는 유료 등급(데이터 학습 제외)이나 다른 공급자로 바꾸고, 개인정보 처리방침에 적어야 합니다.
- Pro 모델은 무료 등급에서 빠졌다는 보도가 많습니다. 기본값인 Flash 계열을 쓰세요.

## 5. 키를 받으면

키는 채팅에 붙여 넣지 말고, 위 방법으로 직접 서버를 실행할 때만 넣어 주세요. 함께 돌려 볼 때는 정해진 시험 문장 몇 개만 소량으로 돌리고 결과를 보고하겠습니다.
