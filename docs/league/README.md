## 가중치에 따라 달라지는 것
- 처음 제안한 5/4/3/2/1 배율로 계산하면 1위 전화 창구(15승), 2위 말로 한 바퀴(14승), 3위 돌봄 설계(13승), 4위 주간 돌봄 편성표(12승).
- 재판관이 "종합적으로 더 낫다"고 고른 쪽만 세면 전화 창구 15, 돌봄 설계 14, 말로 한 바퀴 13, 주간 돌봄 편성표 12.
- 즉 **상위 4개(돌봄 설계·전화 창구·주간 돌봄 편성표·말로 한 바퀴)는 어느 방식에서도 같고**, 그 안의 순서는 "팀원 취향"을 얼마나 치느냐에 달려 있다. 돌봄 설계와 주간 편성표는 팀원 취향 점수가 높고(9.0, 8.2), 전화 창구와 말로 한 바퀴는 LLM 활용·사용자 도움이 가장 높지만 팀원 취향이 낮다(3.0, 2.9).
